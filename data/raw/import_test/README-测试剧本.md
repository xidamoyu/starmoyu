# 前端导入测试材料 · 使用剧本

三个测试文件都在 `starmoyu/data/raw/import_test/`，按下面顺序在「导入管理」页测。

---

## 文件 1：达人谈判复盘笔记-2026Q3.md（非结构化文档通道）

**操作**：导入类型选「非结构化文档」→ 拖入该 .md 文件 → 开始导入

**预期链路**：
1. 提示「已入暂存区」→ 下方暂存区出现一条「导入·文档」记录
2. 点「Agent 预审」→ 几秒后出结论徽标（这份内容干净，应为 **pass**）
3. 点「确认入库」→ 弹确认框 → 确认后自动切块向量化
4. **验证检索**：去对话助手问 →
   ```
   腰部达人的报价一般有多大谈价空间？
   ```
   应能引用笔记里的「12%~18% 让利空间」结论

## 文件 2：聊天截图-达人A美妆合作谈判.png（图片输入路径）

这张是**对话输入框**的测试材料，不是导入页——导入页只收文本/csv。

**操作**：去对话助手页 → 把 PNG 直接**拖进输入框**（或复制后 Ctrl+V 粘贴）→ 附件预览条出现缩略图 → 配文字发送：
```
这是我和达人A李雯的谈判记录，帮我沉淀这次合作的经验
```

**预期链路**：
1. 气泡里显示图片缩略图；工具卡「🗂️ 沉淀达人经验」
2. Agent 会**如实说明无法识别图片内容**（诚实降级），并请你把关键信息用文字补充——这是设计行为，不是 bug
3. 你补充文字后（比如“8万8成交，刊例9万8，预付50%，10月22日发布”）→ 确认卡 → 入库
4. 图片原件已存 MinIO 留档（`chat-attachments/`），等视觉模型接入后可回溯抽取

## 文件 3：商单台账-2026年10月导入.csv（商单台账通道）

**操作**：导入类型选「商单台账」→ 拖入该 csv → 开始导入

**预期链路**：
1. 8 行全部入暂存区（**不会直接写 deal 表**）
2. 逐条（或挑几条）点「Agent 预审」→ 重点看：
   - 正常行 → pass
   - **「暖冬服饰」那行预算是 -20000** → Agent 应给 **reject**（异常值）
3. 对 reject 行点「确认入库」→ 会弹「预审不通过，仍要强制入库吗」警告框
4. 对 pass 行点「确认入库」→ 弹 JSON 编辑框（可修正字段）→ 确认 → deal 表落一条 `DC-IMP-xxx`
5. 去商单台账页搜索「轻颜坊」→ 能看到新导入的单
