## 三、判分方法与偏差控制说明

1. 判分温度取 0；判分提示词给出抽取规则与输出格式约束。
2. **已知偏差（如实记录）**：设计上判分模型应与被评生成模型不同通道，但 DashScope 判分通道因账号欠费不可用，忠实度与答案相关性判分实际由与被评链路同源的模型完成，存在自我偏好风险，本轮忠实度数字应视为偏乐观上界；下一轮评估前需恢复独立判分通道。
3. 大表格型回答（如整表复述刊例价）会导致论断抽取输出过长而超时，忠实度判分输入裁剪为回答正文前 1200 字符（表格部分剔除）；该裁剪使忠实度只覆盖结论性论断，不覆盖表格逐格复述。
4. 忠实度为 0 的样本逐条复盘见第四节。

## 五、结论

1. 答案相关性（0.941）、上下文召回率（0.850）、上下文精确率（0.741）达到设计目标；拒答能力 100%（5/5），语料未覆盖的问题全部正确拒答。
2. 忠实度 0.812 低于 0.90 目标。结合样本复盘，失分主要来自两类：判分模型对「依据上下文表格数据归纳的区间表述」（如把多个报价归纳为「2 万至 10 万元」）判为无直接支持；以及回答在引用了多个来源块时，部分论断对应的内容块因上下文 4000 字符截断未被送入判分上下文。前者是判分口径过严（归纳性表述被误判），后者需要在判分时放宽上下文窗口或只对引用编号对应的块判分。
3. 数值保真 83% 未达 100% 目标。失真数值多为商单编号与截断表格行，属于校验正则把标识符当作数值的口径问题与上下文截断问题，尚未发现金额/回报率被改写的实锤案例；数值保真校验规则需排除编号类标识并在引用块范围内比对。
4. 1 例「部分拒答」暴露多约束题（预算+类目+平台三重约束）的正确行为应有更细的判定档位。
