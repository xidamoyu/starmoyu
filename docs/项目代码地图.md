# 项目代码地图 — 哪些代码在运行、在哪里

> 生成日期：2026-10-08。本文回答一个问题：**当前版本（v2 对话式智能体）实际运行的是哪些文件**。
> 结论先行：运行时入口 = `src/server/api.py`（FastAPI）→ `src/agent_graph.py`（MCAgent 智能体）→ `src/agent_tools.py` 等三组工具 → `src/starmoyu/` 基础包（检索/存储/模型通道）。v1 遗留全部在 `legacy/`。

## 一、运行链路（一条主线）

```
浏览器 Vue3 (frontend/)
   │ HTTP / SSE
   ▼
src/server/api.py          ← FastAPI 全部 41 个接口（唯一入口）
   │
   ├─ src/agent_graph.py   ← MCAgent：LangGraph agent⇄tools 循环 + checkpointer
   │     │ bind_tools 19 个工具
   │     ├─ src/agent_tools.py   基座 7 工具（检索/达人/方案/跟进/简报…）
   │     ├─ src/m4_tools.py      沉淀 2 工具（save_interaction / list_kol_traits）
   │     └─ src/m5_tools.py      全生命周期 10 工具（结案/brief/品牌特质…）
   │
   ├─ src/server/service.py        会话与消息（列表/改名/删除/标题）
   ├─ src/server/m4_service.py     沉淀服务（确认卡原子入库）
   ├─ src/server/m5_service.py     结案效果服务（被 m6_service 引用）
   ├─ src/server/m6_service.py     商单变更审批流（旧值快照/原子写回）
   ├─ src/server/m7b_service.py    导入三通道 + 质检预审 + 双审
   └─ src/server/sediment_service.py  案例沉淀（预览/确认/增量回流）
   ▼
src/starmoyu/ 基础包（全部在用）
   ├─ storage.py     PostgreSQL(14表) + Milvus + MinIO 客户端（15 处引用）
   ├─ retriever.py   混合检索：BGE向量 + BM25 → RRF 融合 → 去重 → 重排序（7 处引用）
   ├─ llm.py         模型通道：qwen3.8 对话 / qwen-plus 判分 / qwen-vl 识图（12 处引用）
   ├─ assistant.py   quick_query（检索+带引用生成，RAGAS 评测也走它）
   └─ ingest.py      语料入库（⚠ 禁直接跑，会 TRUNCATE kol_profile）
```

## 二、前端（frontend/src/）

| 文件 | 作用 |
|---|---|
| views/Layout.vue | 全局布局：顶栏 + 分组侧栏（hover 弹目录）+ 唯一会话列表 |
| views/ChatView.vue | 对话主界面（流式渲染、确认卡、工具事件展示） |
| views/LoginView.vue | JWT 登录 |
| views/DealList.vue / KolManage.vue / ProposalReview.vue / UserManage.vue / AdminImport.vue | 台账 / 达人库 / 审批中心 / 用户管理 / 导入管理 |
| stores/chat.ts | 会话状态（convList / 流式消费 / 改名删除） |
| api/index.ts + api/stream.ts | REST 封装 + SSE 流解析 |
| components/Md.vue / DealDrawer.vue | Markdown 渲染 / 商单抽屉 |

## 三、评测体系（scripts/ 仅存 5 个，全部在用）

| 文件 | 作用 |
|---|---|
| eval_v4_retrieval.py | 检索五指标 + 五组消融（107 题评测集） |
| eval_v4_ragas.py | RAGAS 四指标 + 业务规则校验（独立判分） |
| rebuild_milvus_v4.py | 向量库全量重建（以 PG 为唯一数据源） |
| eval_v3_retrieval.py / eval_v3_ragas.py | v3 首轮评测（报告存档用） |
| reports/eval_set_v3.json | 107 题评测集本体 |

评测报告：`reports/检索评测报告-v3|v4.md`、`生成质量评估报告-v3|v4.md`、`评估总报告-v3|v4.md`；git 内副本在 `docs/评估报告-v3|v4/`。

## 四、运维脚本

| 文件 | 作用 |
|---|---|
| start.sh / start.bat | 一键启动（含 8000 残留进程清理） |
| stop.sh | 一键关闭（--with-wsl 连容器一起停） |
| scripts/wsl_maintenance.bat + wsl_tasks_hidden.vbs | 计划任务（每5分钟，隐藏窗口）：WSL IP 变化同步 portproxy + MinIO 僵死自愈 |
| scripts/wsl_portproxy_sync.ps1 | portproxy 同步逻辑本体 |
| scripts/wsl_keepalive.sh | WSL 保活 + MinIO 探活（手动/备用） |

## 五、legacy/（v1 遗留，不参与运行，仅存档）

| 文件 | 是什么 | 为什么废弃 |
|---|---|---|
| app.py | Streamlit 三 tab 前端 | v2 改 Vue3 |
| src/starmoyu_graph.py | v1 十节点 LangGraph 固定流水线（router 三分支） | 控制流硬编码：路由错一步全错；v2 改为 bind_tools 工具循环，控制流交模型 |
| scripts/ 下 43 个 9 月脚本 | v1 探针/迁移/分层验证 | 历史迭代产物 |

## 六、数据目录（git 忽略，不进仓库）
